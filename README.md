Astro Collector



Descripción

Astro Collector es un videojuego de plataformas 2D en el que el jugador controla a un astronauta que debe recorrer un escenario, superar obstáculos y recolectar cinco monedas para completar el nivel.



Objetivo

Desarrollar un prototipo jugable que integre mecánicas de movimiento, físicas, colisiones, animaciones, interfaces gráficas y efectos de sonido.



Plataforma y configuración técnica

\- Plataforma: PC (Windows).

\- Motor: Unity 6.

\- Lenguaje: C#.

\- Renderizado: Universal Render Pipeline (URP 2D).

\- Control de versiones: Git y GitHub.



Se seleccionó Windows por su accesibilidad, facilidad de desarrollo y compatibilidad con los equipos utilizados.



Mecánicas principales

\- Movimiento horizontal y salto.

\- Recolección de monedas.

\- Contador de progreso.

\- Condición de victoria.

\- Reinicio de partida.

\- Cámara con seguimiento del personaje.

\- Música ambiental y efectos de sonido.

\- Menú principal.



Controles

\- A/D o flechas direccionales: desplazamiento.

\- Barra espaciadora: salto.

\- Mouse: interacción con los botones.



Instalación y ejecución

Para ejecutar el videojuego, descargar el repositorio, acceder a la carpeta Build y abrir el archivo ejecutable.



Para editar el proyecto, abrir la carpeta Project mediante Unity Hub.



Dependencias

\- Unity 6.

\- Universal Render Pipeline.

\- TextMeshPro.

\- Recursos gráficos y sonoros incluidos en el proyecto.



Riesgos y mitigaciones



| Riesgo | Mitigación |

|---|---|

| Pérdida de avances | Respaldos mediante GitHub. |

| Conflictos de integración | Uso de ramas independientes. |

| Errores de colisiones | Pruebas de movimiento y plataformas. |

| Problemas de rendimiento | Utilización de recursos gráficos 2D. |
